# PersonalAI-Android

Native Android client for the PersonalAI chat platform.

## Current status

Initial Android/Jetpack Compose project scaffold is in place.

## MVP roadmap

- [x] Initialize Android application structure
- [x] Add Compose-based launcher screen
- [ ] Connect to the chat backend API
- [ ] Implement conversations and message history
- [ ] Add loading, retry, error, and offline states
- [ ] Add model selection and settings
- [ ] Add tests and CI
- [ ] Add Trace, tools, files, authentication, Treasury, MCP, and memory integrations

## Build

Open the project in Android Studio with a recent Android Gradle Plugin-compatible environment, then run the `app` configuration.
